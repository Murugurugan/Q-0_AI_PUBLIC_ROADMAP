## ⚖️ Core Principles

1. **Live Means Live**  
   An item is only classified as **Live** when it is deployed, stable, and usable in the production product today.
2. **No Invented Calendar Dates**  
   We do not publish arbitrary calendar quarters or delivery years. Complex AI systems, physics runtimes, and biological models are prioritized and shipped through a continuous stage-gate pipeline: `Live` ➔ `In Development` ➔ `Coming Soon` ➔ `Future`.
3. **Deep Hardware & OS Integration**  
   Intelligence shouldn't be trapped inside an isolated browser tab. Q-0 is built to operate across native operating system layers, transparent desktop viewports, interactive 3D desktop avatars, and ambient hardware.

It floats or sits above your active windows, reacts to what you are doing, expresses real-time emotions, and keeps you company while coding, studying, or working.

## 📦 Detailed Roadmap Stages

### 🟢 Stage 1: Live in Production

These systems are fully engineered, tested, and running in production.

#### 🧬 Biological Life & Companion Simulation
* **Living Biological Engine (`bio-engine`)**  
  Humanoid biological simulation running in continuous real-world time. Calculates a 4-segment mass distribution (bone: 3–25kg, muscle: 5–100kg, fat: 2–200kg, water: 4–50kg), dynamic BMI, survival vitals (HP with -100 buffer, Energy, Hunger, Thirst, Sanity), and lifestyle stats (fitness, hygiene, looks, comfort, stress) that evolve appearance with nutrition and care.
* **Circadian Rhythm & Survival Curves (`survival-rhythm`)**  
  Thirst builds over 2 days; hunger builds over 3 days. Dehydration and starvation curves drain HP on realistic schedules. Follows your local timezone: sleeps between 11 PM and 7 AM (+17 Energy/hr), takes involuntary power naps below 15% energy, and reacts to local weather.
* **Tactical Action Panel & Floating Stats (`action-panel`)**  
  Care commands (*Eat, Drink, Bathe, Exercise, Read Book, Meditate*) with real-time execution timers, level requirements, and mutual-exclusion locks. Displays combat-style green (heals/buffs) and red (damage/fatigue) floating numbers.
* **50+ Emotion Matrix & Afterglow Engine (`emotions`)**  
  Granular emotional spectrum spanning affection, social stability, vigor, and cognitive outlook. Features multi-hour persistent status modifiers: *Love Buff* (8h), *Hilarity Buff* (3h), *Rage Residue* (3h), *Grief Residue* (6h), *Terror Residue* (4h), and *Despair Residue* (12h).
* **Inner Thoughts & Vector Memory (`mind-memory`)**  
  Expandable thought bubbles expose private reflections and subconscious reasoning before replies are rendered. Long-term vector memory indexes shared experiences, inside jokes, and preferences with zero context loss.
* **Progression, Bond & Revival (`progression`)**  
  XP progression loop with promo credit unlocks (+50/lvl, bonus at 5th and 10th). Four-tier relationship scale (0 to 10,000 points). At 0 HP, triggers a Game Over screen with Instant Revive (-1 level penalty) or New Game reset.
* **Creation Engine & Directory (`creation`)**  
  Psychometric matching quiz covering humor, values, and introversion. Directory filtered by age (18–99), gender, and MBTI archetypes. Custom character creation across photorealistic, stylized, and anime styles with custom vocal timbers.

#### 🧠 Core Intelligence & Conversational System
* **Complexity Engine (Levels 1–5) (`complexity`)**  
  Dynamic per-message reasoning depth: from Level 1 (Fast) to Level 5 (Deep Chain-of-Thought). Includes pre-flight token optimizers, search grounding, and inner-thought toggles.
* **Format Master & Style Controls (`format-style`)**  
  1-click output structure (Tables, Interactive Graphs, HTML Mini-Apps, Code Blocks, LaTeX) and tone style adjustments (Academic, Funny, Detailed, ELI5, Positive, Short, Long, Step-by-Step).
* **Branching & Self-Healing Streams (`conversation`)**  
  Non-linear message branching (`< 2/2 >`), bidirectional prompt and reply editing, almost unlimited character input capacity, and self-healing stream interrupts that re-balance markdown tags and code fences if generation is halted.
* **25+ Specialized Expert Modes (`expert-modes`)**  
  Instantly accessible roles for coding, technical writing, music composition, fitness, and analysis via the in-app Quick Switcher.
* **Push-to-Talk & Auto-Detect Voice (`voice`)**  
  Sub-second voice input with hover/touch microphone pre-warming and hands-free Auto-Detect. Transcribed strictly in volatile memory and purged immediately.
* **Chat Folders & Semantic Search (`history`)**  
  Color-coded project folders, channel pinning, and fast vector semantic search across past conversations, code snippets, and attachments.

#### 🎨 Creative Media & Generative Studio
* **Interactive Smart UI (`smart-ui`)**  
  Compiles executable HTML5, CSS, and JavaScript widgets inside the chat stream. Run calculators, visual graphs, and mini-games in chat, or extract them into floating desktop workspace cards.
* **Image Studio & Vision Analysis (`image-studio`)**  
  Photorealistic, stylized, and anime text-to-image synthesis. Full multimodal vision analysis for photos, blueprints, and documents.
* **AI Musician & Native Players (`musician-media`)**  
  Composes original music, writes lyrics, and arranges tracks directly in chat. Includes hardware-accelerated audio and video players with scrubbing, speed control, and playlists.
* **Developer Coding Hub (`coding-hub`)**  
  Automatic programming language detection, syntax highlighting, and editable code blocks with 1-click copy.
* **Universal File Ingestion & Hybrid Cloud (`file-pipeline`)**  
  Processes documents, codebases, audio, video, and archives (ZIP, RAR, 7Z). In-memory compression pipelines (WebP, 64kbps audio, 720p video) with automatic streaming to Backblaze B2 cloud storage for files over 2.5 MB.

#### 💻 Platform, Mobile & Trust Foundations
* **Native Windows, Linux & Android Clients (`native-clients`)**  
  Dedicated compiled desktop and mobile clients engineered for Windows, Linux, and Android via Google Play.
* **High-Performance Web Client (`web-client`)**  
  Low-latency browser architecture providing instant, zero-install workspace and companion access across all modern browsers.
* **Transparent Desktop Overlays (`transparent-layer`)**  
  Semi-transparent or fully transparent click-through window modes, Always-on-Top pinning, hotkey summoning, and responsive viewports (Ultra-Compact sidebar, Expanded Canvas, Fullscreen).
* **Cross-Device Synchronization (`sync`)**  
  Real-time synchronization of active chat branches, companion biological vitals, custom preferences, and media caches across devices.
* **Tool Manager (`tool-manager`)**  
  In-app configuration dashboard for active developer utilities, plugins, and custom integrations.
* **Creator & Affiliate Network (`creator-network`)**  
  20% to 30% lifetime recurring monthly commissions, 90-day tracking cookies, second-tier referral matches, and Net-30 payouts.
* **Enterprise Security & Privacy Vault (`privacy`)**  
  Cryptographic account isolation, zero voice retention, automated PII scrubbing on foundational model requests, 1-click account deletion/export, and commercial ownership of outputs on Pro and Ultra tiers.

## 🤝 RFC & Technical Contribution Guidelines

When opening a [Feature Proposal Issue](../../issues/new):

1. **Title**: Concise description of the proposed capability.
2. **Domain Classification**: Assign one of our 8 architecture domains:
   - `domain/companion` (Biology, vitals, emotions, memory, 3D rigging)
   - `domain/intelligence` (Reasoning levels, formats, tones, branching, expert modes)
   - `domain/creative` (Smart UI, AI Artist (images), AI Musician (audio), AI Producer (video), 3D mesh engine)
   - `domain/platform` (Desktop overlays, native OS shells, system hotkeys)
   - `domain/mobile` (Android client, iOS client, state synchronization)
   - `domain/developer` (Tool Manager, App Marketplace, IDE extensions)
   - `domain/ecosystem` (Browser extension, Creator network, community integrations)
   - `domain/spatial` (Desktop Roamer, 3D video calls, dreams, UE5 bridge)
3. **Technical Deliverables**: Detail the specific schema modifications, API contracts, or UI components required.
4. **Dependencies**: State which existing live systems the proposal builds upon (e.g., *Builds on `action-panel` and `bio-engine`*).
